# Leon-Europe-Retail

它服务于两个长期方向：

公开主定位：

Leon｜后Action时代实战家

## 唯一归属原则

一个文件只能有一个主要事实源。

其他地方通过链接引用。

不要让同一类内容散落在多个一级目录。
