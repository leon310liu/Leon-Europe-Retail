## 内容工厂极简原则

内容工厂按“成品”组织，不按“工序”组织。

同一条内容资产尽量放在同一个内容单元中。

不要再为流程拆出新的：

- 知识卡库
- 脚本库
- 字幕库
- 封面库
- 视频项目库
- 数据卡库
- 白皮书生产库

单条视频相关内容优先放在：

`20-内容工厂/01-视频号/对应系列/CONTENT-ID-标题/`

单条公众号文章优先放在：

`20-内容工厂/02-公众号/对应系列/CONTENT-ID-标题/`

## 唯一归属原则

一个文件只能有一个主要事实源。

其他地方通过链接引用。

历史目录如果已经迁移完成、没有独有内容、引用已修复，应删除旧副本。

Git 历史已经保留历史版本，不需要用旧目录永久保留重复文件。

## CONTENT-ID原则

同一思想资产在不同平台必须共享同一个 CONTENT-ID。

当前系列代码：

- HA = 后Action时代-欧洲华人百货
- SH = 深度出海元年
- RS = 重新开始
