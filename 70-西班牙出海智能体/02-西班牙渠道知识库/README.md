# 02 西班牙渠道知识库

渠道知识按 8 类组织。分类是智能体判断的第一层：先判断产品适合哪些渠道大类，再调用具体公司的 Channel Intelligence Card 做匹配。分类用于检索和比较，不代表每家公司只能归入一类；具体公司以渠道智能卡为唯一事实单元。

所有动态事实应带来源和核验日期。Leon 的经验判断进入 LEON VIEW，一线现场信息进入 Field Intelligence，二者不能冒充公开事实。

每张卡同时保留两套表达：

- 行业语言：用于准确描述商业组织，例如“本土批发采购集团”。
- Leon 解释语言：用于让中国企业快速理解，例如“老外版华人批发商”。

解释语言是认知桥梁，不是法律主体或公司自称，不得写入公开事实字段。
