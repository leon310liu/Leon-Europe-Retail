# 02 家电消费电子

收录以家电、消费电子及相关服务为核心的专业渠道。研究重点包括品类价格带、产品差异化、导购展示、售后、退货和价格竞争。

## 已建Channel Card

- MediaMarkt Spain — 大型消费电子零售 / Marketplace双路径
- Sinersis — Buying Group / 区域平台网络
- Best Phone Mundo Móvil — B2B消费电子批发与全国分销

## 研究规则

对该分类中的渠道，需要明确区分：
- 终端零售商
- Buying Group / 区域平台
- B2B批发分销商
- Marketplace平台

不得仅因都经营消费电子而视为相同进入模式。
