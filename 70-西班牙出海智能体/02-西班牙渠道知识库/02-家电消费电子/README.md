## 研究规则

对该分类中的渠道，需要明确区分：
- 终端零售商
- Buying Group / 区域平台
- B2B批发分销商
- Marketplace平台

不得仅因都经营消费电子而视为相同进入模式。

对于采购集团/分销集团，还必须进一步分字段区分：
- socios / asociados（成员主体）
- plataformas（区域平台）
- almacenes（仓库/物流节点）
- puntos de venta（终端销售点）

这些字段不能因为中文都可被宽泛翻译成“平台/网点”而混写；如官网不同页面口径冲突，应保留来源页与抓取日期。

对促销目录、区域门店目录和电商SKU快照，还必须区分：
- 出现在前台销售/促销页面；
- 区域平台实际供货；
- 集团总部统一采购或框架协议。

三者不能互相替代证明。

对于同时经营自营零售与Marketplace的平台（如MediaMarkt、Fnac），还必须额外区分：
- 平台自营采购 / 自营库存；
- 第三方Marketplace卖家；
- 实体门店可售/可展示状态。

“品牌出现在平台网站”不得自动推导为“品牌已进入该零售集团采购体系”。
