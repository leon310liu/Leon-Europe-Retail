## 1. Channel Role

PcComponentes 是西班牙本土大型科技/消费电子零售平台，当前同时经营：

- PcComponentes 自营电商
- 第三方 Marketplace
- 4 家实体门店（Madrid、Barcelona、Murcia Thader、Alhama de Murcia）

官方首页当前自述拥有 100,000+ 可售商品、31,700㎡设施面积，并列出上述 4 家实体店。

**AI Analysis:** 对消费级电子产品，尤其 001 AI吹风机，应将 PcComponentes 视为“专业科技零售 + Marketplace”双路径渠道，而不是单纯电商平台。

## 2. Marketplace vs. Self-Retail — 必须严格区分

PcComponentes 官方 Marketplace 条款明确：

- 第三方卖家与消费者之间直接形成买卖合同；
- 第三方卖家自行定价、销售并负责售后；
- 商品页通过 `Vendido y enviado por` 标识实际卖家；
- PcComponentes 自营商品与第三方 Marketplace 商品可通过卖家字段区分。

因此：

> “品牌在 PcComponentes 网站可见” **不能自动推导为** “品牌已进入 PcComponentes 自营采购体系”。

对于 Channel Card 和案例研究必须分别记录：

1. Marketplace third-party seller
2. PcComponentes self-retail / self-stock
3. Store availability / pickup
4. Supplier / central buying relationship（如有公开证据）

## 3. Current Marketplace Entry Rules — 2026 Snapshot

PcComponentes 2026 年最新卖家帮助中心显示：

- Marketplace 卖家账号月费为 **€39.99 + VAT**；
- 首月免费；
- 从第二个月起，仅在当月产生订单时收取月费；
- 月费与订单佣金分开计算；
- Marketplace 可配置 Spain / France / Italy 等不同国家销售渠道，但启用国家渠道并不等于自动满足当地法规与物流要求；
- 卖家必须遵守平台售后标准，包括退货、保修、消费者投诉机制；
- PcComponentes 2026 帮助中心已单独要求卖家维护 GPSR 产品安全信息。

对于运费，官方卖家规则当前要求：

- 订单金额达到 €50（岛屿除外）时提供免费配送；
- 保修流程中不得向消费者收取配送费用。

**AI Analysis:** 对中国品牌而言，Marketplace 可以作为较低门槛的消费者测试路径，但进入前仍需解决欧盟/西班牙产品合规、售后、退货、配送和经济运营主体问题，不能把“开卖家账号”视为完成市场进入。

## 6. Entry Path Model for Consumer Electronics

对消费电子品牌，PcComponentes 应至少拆成三层进入路径：

### Path A — Marketplace Test
品牌 / 欧盟销售主体 → PcComponentes Marketplace → 西班牙消费者

用途：
- 低门槛市场验证
- 价格与评论测试
- 建立搜索与销量数据

### Path B — PcComponentes Self-Retail
品牌 / 本地进口与供货主体 → PcComponentes 自营采购 / 自营库存 → 消费者

用途：
- 获得平台自营背书
- 提高履约和售后体验一致性
- 可能获得更强营销和类目推荐资源

### Path C — Omnichannel / Store Validation
自营 SKU → 门店可售 / 陈列 / 取货 → 线上线下一体化

目前需要继续核验：
- 哪类 Beauty / Personal Care 产品进入实体陈列；
- Beauty / Hair Tools 的具体 buyer / category owner；
- Marketplace 高表现 SKU 是否存在升级到自营采购的标准路径；
- 供应商 MOQ、账期、返点、marketing contribution、退货和售后条款。
