## 1. 公开事实

### 渠道定位

E-UREKA Electrodomésticos 官方将自己定义为西班牙全国范围的家电与消费电子 Outlet 零售/分销企业，并同时运营实体门店与电商。

官方当前页面称其拥有 **20 家实体门店**，分布在 Soria、Tudela、Logroño、Burgos、Palencia、Teruel、Huesca、Calahorra、Segovia、Aranjuez、Villena、Aranda de Duero、Valdepeñas、Cuenca、Ávila、Ondara、Zamora、Valladolid、León、Ciudad Real，并设有位于 Almazán（Soria）的物流仓库。

### 001 AI吹风机相关品类

Eureka 官方商品结构明确包含：

`Pequeño Electrodoméstico → Cuidado Personal → Secadores`

因此，Eureka 不是仅经营大家电的 Outlet；其现有品类结构已经覆盖个人护理小家电与吹风机。

### 供应商入口

Eureka 官网导航当前公开存在 **“Ser proveedor（成为供应商）”** 入口。这是一个值得后续核验的直接供应商接触信号，但目前公开页面不足以确认其完整供应商准入流程、采购联系人、首单量、返点、账期或是否接受新国际品牌。

### 渠道形态

当前可公开确认：

- 20 家实体门店；
- 全国线上销售；
- Outlet / 低价家电定位；
- 自有物流仓节点；
- 商品体系覆盖 PAE 与 Personal Care；
- 官网存在供应商入口。

## 2. AI Analysis（不是 Leon View）

对于 001 AI吹风机，Eureka 可作为一条与 MediaMarkt、Sinersis、Expert 不同的补充路径研究：

**品牌/西班牙进口主体 → Eureka 集中采购/Outlet体系 → 20家实体门店 + 电商 → 消费者**

其价值更可能在于：

1. 进入西班牙中型城市和区域城市的线下家电消费场景；
2. 对库存、尾货、价格带较敏感的 Outlet 零售测试；
3. 在非一线核心城市验证 Personal Care 小家电的实际需求；
4. 若其“Ser proveedor”机制对新品牌开放，可能形成比大型全国连锁更低的初期接触门槛。

但不能因为官网有供应商入口，就推断：

- 其接受所有新品牌；
- 其采购决策完全中央化；
- 其愿意接受高价/高端定位吹风机；
- 其承担进口商或 RII-AEE/EPR 责任；
- 产品进入官网即可进入全部实体店。

## 3. 对001 AI吹风机的待验证项

- 当前吹风机品牌、SKU与核心价格带；
- 是否已经经营 100,000+ RPM / BLDC 高速吹风机；
- Personal Care 采购负责人；
- “Ser proveedor”实际申请流程；
- 首单量 / MOQ；
- 采购合同与开票主体；
- 账期、返点、促销费用；
- 是否支持 Web-only 试销；
- 是否允许先少数门店试销再扩店；
- Outlet模式是否要求特殊折扣或清库存条件；
- 西班牙售后/SAT要求；
- RII-AEE / EPR / RAEE责任主体；
- 是否存在 Private Label / 独家SKU合作。

## 4. 数据治理

- “20家门店”为 Eureka 官方当前页面口径，需保留抓取日期，未来门店开闭会变化。
- 官方使用“全国Outlet领先”等自我描述，不应视为经第三方审计的市场份额排名。
- “200,000+ clientes satisfechos”为官网自述，不作为渠道规模核心字段。
- 必须区分：官网上架、实体店库存、中央采购关系、Outlet清货合作四种不同状态。
