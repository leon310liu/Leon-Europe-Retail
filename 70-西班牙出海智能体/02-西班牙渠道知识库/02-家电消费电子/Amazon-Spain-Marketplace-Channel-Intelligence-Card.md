# Amazon Spain — Marketplace Channel Intelligence Card

> Knowledge type: Public facts + AI analysis  
> Leon View: **None added**  
> Last checked: 2026-08-25

## 1. Channel Role

Amazon.es 是西班牙核心综合电商与 Marketplace 之一。对消费级电子产品，应将其拆成多个不同商业层级，而不能笼统写成“进入 Amazon”：

1. 第三方 Seller Marketplace
2. Seller-fulfilled / Merchant Fulfilled
3. FBA（Fulfilment by Amazon）
4. Seller Fulfilled Prime
5. 品牌直营 / Brand Registry 相关运营
6. Amazon 自营采购（如存在公开或商务证据）

**AI Analysis:** 对中国消费电子品牌，Amazon.es更适合被建模为“可直接进入的市场测试与销售平台”，但Marketplace销售不能自动等同于Amazon自营采购，也不能替代西班牙本地合规、售后和渠道建设。

## 2. Seller Entry — 2026 Official Rules Snapshot

Amazon Spain 官方 Seller 注册指南当前要求企业卖家准备并通过：

- 企业合法性验证
- 主要联系人身份验证
- 商业/居住地址验证
- 联系人与企业关系证明
- 信用卡信息
- 银行账户信息
- 受益所有人和法定代表相关资料（视企业结构而定）

官方当前提供：

- Individual plan：€0.99 / 每件售出商品 + referral fee
- Professional plan：€39 / 月（未含VAT）+ referral fee

Amazon明确指出，不同产品类别可能开放程度不同，部分品类或品牌需要额外授权。

## 3. Fulfilment Layer — FBA vs Seller-fulfilled

Amazon Spain 当前提供至少两种重要履约模型：

### FBA
卖家将库存交给 Amazon 物流网络，由 Amazon 负责拣货、包装、配送及部分客户服务流程。

2026官方资料显示：

- 西班牙约 3/4 的 FBA 订单可在2天或更短时间送达（Amazon官方口径）；
- 自2026-04-17起，Amazon对包括Spain在内的多个欧洲站点FBA履约费增加1.5%的燃油及物流附加费。

### Seller Fulfilled Prime
卖家保留自有库存和仓库，但可在满足Prime服务标准后使用Prime标识。

当前公开标准包括：

- 满足品类和库存所在地对应的配送承诺；
- 至少90%的准时送达率；
- 订单直接从卖家仓库履约。

**AI Analysis:** 对001 AI吹风机或其他消费电子新品，FBA和Seller Fulfilled Prime的库存责任、退货成本、配送速度和利润结构不同，Channel Card和GTM方案中应单独建模，不能只写“Amazon渠道”。

## 4. Spain EPR / RAEE Compliance — Marketplace Hard Gate

Amazon Spain 官方EPR页面当前明确：

如果商品属于受生产者延伸责任监管的类别，例如：

- 包装
- WEEE / RAEE（电子电气设备）
- 电池

且卖家根据西班牙法规属于生产者，则需要提供相应的EPR注册号，并通过Seller Central的EPR Compliance Portal提交。

如果卖家未完成要求，Amazon Spain可根据其公开规则将卖家纳入相关“代付”机制并从卖家账户扣除对应费用。

**AI Analysis:** 对001 AI吹风机，Amazon Marketplace准入不能只看“账号是否注册成功”，至少还应同时核验：

- RII-AEE / RAEE责任主体
- EPR注册号
- 包装EPR
- 电池EPR（如产品/附件涉及）
- VAT责任
- GPSR / 产品安全信息
- 西班牙售后与退货方案

Marketplace可作为测试路径，但不应绕过Spain Market Entry Compliance Layer。

## 5. Amazon Spain Scale — Company Public Snapshot

Amazon在2026年公开的西班牙经济影响资料中披露：

- amazon.es 于2011年9月上线；
- 累计在西班牙业务投资超过€25bn；
- 西班牙固定员工超过30,000人；
- 约17,000家西班牙中小企业在Amazon店铺销售。

Amazon另披露，其2025年西班牙相关业务总收入超过€9bn，并在2025年投入超过€6.5bn用于基础设施、人员和业务运营。

**Data boundary:** 以上是Amazon公司整体西班牙业务口径，不等同Amazon.es Marketplace GMV，也不能直接用于推算吹风机、PAE或第三方卖家市场份额。

## 6. Relevance to 001 AI Hair Dryer

Amazon对001的主要价值不是“证明线下渠道已经接受产品”，而是：

### Path A — Direct Marketplace Test
品牌 / EU或Spain销售主体 → Amazon.es Seller → 消费者

可用于：
- 价格测试
- 内容和搜索关键词测试
- 评论积累
- 广告转化测试
- SKU/颜色/附件组合测试

### Path B — FBA Scale-up
品牌 → Amazon FBA库存 → Amazon履约 → 消费者

重点验证：
- 退货率
- FBA费用
- 单位经济模型
- 库存周转
- 旺季仓储与补货

### Path C — Professional Seller-fulfilled / Prime
本地或欧盟库存 → Seller Fulfilled Prime → 消费者

适用于已经具备欧洲仓配能力的品牌。

### Path D — Retail / Distribution Escalation
Amazon取得真实销售、评论与消费者数据后，可作为后续与Spain importer、distributor、Buying Group或self-retail buyer沟通的市场证明之一。

**Important:** 这只是潜在GTM逻辑，不是公开事实，也不是Leon View。Amazon表现好并不自动转化为线下采购资格。

## 7. Data Governance Rules

以后研究Amazon Spain时必须区分：

- Amazon Marketplace third-party seller
- FBA
- Merchant Fulfilled
- Seller Fulfilled Prime
- Brand Store / Brand Registry
- Amazon self-retail / first-party procurement（如有证据）
- Seller legal entity
- Stock location
- VAT country
- EPR / RAEE registration status
- Seller of record
- Product review / ranking snapshot date

不得将“Amazon.es上可以买到”自动写成：

- Amazon自营采购
- 西班牙线下渠道验证
- 西班牙本地进口商已建立
- 产品已满足全部Spain合规要求
