## 本类渠道统一核验框架
不能因为结构类似就默认交易机制相同。每张卡必须分别核实：
1. 谁批准新供应商/新品牌；
2. 是否存在中央仓、哪些SKU进入中央库存；
3. 是否允许会员直接向供应商/制造商采购；
4. 谁向购买方开票；
5. 谁承担付款与信用风险；
6. 会员自主权及是否可同时使用其他采购集团/供应商。

公开事实、AI分析、Leon View必须分层记录；自动研究不得自行生成Leon View。
