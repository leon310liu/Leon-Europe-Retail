# 05 本土批发采购集团｜“老外版华人批发商”

收录西班牙本土进口商、批发商、合作社和采购集团。研究重点包括进口责任、覆盖区域、下游客户、采购权、库存承担、批发利润和渠道冲突。

## Leon 解释性定位

为了让中国企业快速理解，可把这类渠道称为“老外版华人批发商”。这个类比描述的是共同生态位置：它们都连接上游品牌/工厂与大量独立零售门店，能够降低逐店开发成本。

这个类比不代表两套体系完全相同。05 类常见合作社、采购集团、中央服务和会员机制；采购可能由中央仓与会员直采共同完成，合同、品牌、营销和门店支持也更制度化。智能体对外输出时必须同时说明共同点和差异。

## 典型生态模型

```text
品牌/厂家
  ↓
中央采购、仓配或服务平台
  ↓
会员零售店/区域专业门店
  ↓
消费者或专业客户
```

部分组织同时存在：

```text
品牌/厂家 → 会员门店直接采购
```

因此不能把“进入总部”自动解释为“全国铺货”。渠道卡必须分别核验中央采购权、会员自主权、区域覆盖和实际推动机制。

## 与 04 华人百货渠道的战略对照

- 共同点：聚合分散零售终端，为上游提供网络化覆盖。
- 关键差异：下游业态、组织治理、合同机制、采购路径与专业品类不同。
- 对中国企业的价值：专业产品可能通过采购集团比逐店开发更有效率，也可能比国际大连锁更适合作为第一阶段突破口。
- 主要风险：误以为签下中央组织即可统一铺货；忽略会员接受、区域商业关系和本地服务能力。
