# 产品画像字段

## 首轮决策必需字段

- 产品名称与核心用途
- Vertical：使用受控标签库
- FOB 成本范围：币种、贸易条款、数量条件
- 建议零售价：目标国家、是否含税、币种
- 品牌状态：无品牌 / 已有品牌 / 待确定
- 路径偏好：贴牌 / 自主品牌 / 两者均可
- 销售偏好：线上 / 线下 / 全渠道 / 未确定
- 企业欧洲落地能力：认证、进口主体、仓储物流、售后、本地团队/合作伙伴、渠道经验

## 补充字段

目标用户、核心卖点、差异化证据、认证与合规状态、MOQ、产能、交期、包装语言、样品状态、已有市场与销量、营销素材、预算、时间目标、风险承受能力。

每个字段应记录值、来源、确认状态、更新时间和置信度。范围优于伪精确数字。
