# 05 西班牙本土批发采购集团｜Leon View

> 本文记录Leon定居西班牙并深入一线开发本土渠道后形成的实战认知。费用、周期等数字为Leon经验范围，后续以真实合同和公开资料持续验证。

## 1. 为什么这个渠道容易被中国企业忽略
Leon在美的负责欧洲市场时几乎没有真正接触到这一层渠道，因此曾产生“西班牙怎么没有强大的本土零售体系，似乎都是英法德跨国连锁”的疑问。定居西班牙、深入开发华人百货和西班牙本土渠道后，才逐步看清本土批发采购网络。

它是西班牙独立零售体系的重要“毛细血管供货系统”。中国企业看到的可能只是一家区域批发/采购公司，Leon看到的则是它背后经过多年沉淀形成的大量本地独立零售门店网络。

## 2. Coferdroza样板认知
以Coferdroza为例，可以把它理解为西班牙本土的批发/采购组织：拥有中央体系，并覆盖一定区域内的本地独立零售会员。

典型供货存在两种模式：
1. 供应商 → 中央仓/集团采购 → 会员店；
2. 供应商进入集团供应体系 → 会员店直接向供应商采购。

两种模式的报价和费用结构可能不同，因此不能只问“给Coferdroza什么价格”，必须先弄清楚交易模式。

## 3. 合作流程
Leon实战理解中的典型流程：
找到中央采购/品类负责人 → 介绍企业与产品 → 判断品类和商业条件 → 达成意向 → 谈判并签订合作协议 → 建立供货关系。

与华人百元店不同，本土企业通常是先把合同、商业条件和付款规则谈清楚，再发生第一笔正式交易。

## 4. 不要漏算合同费用
Leon实际合作经验中，这类体系除采购价格外，还可能存在：
- 广告/市场支持费：约1%–3%；
- 总部管理费用：约1%–3%；
- 年终返点：约1%–5%；
- 内部展会、订货会赞助费或摊位费：按次数、面积或协议计算；
- 其他合同约定费用。

以上为Leon经验范围，不代表所有采购集团统一收费。未来收到真实合作协议后，应建立“合同费用结构库”，用于单品盈利测算和报价反推。

## 5. 区域性是核心特征
西班牙本土批发采购网络具有很强区域属性。一个在加泰罗尼亚深耕多年的批发网络，并不天然能复制到马德里；不同区域存在各自长期经营的本地企业和零售关系。

这些关系可能经过几十年甚至两三代人沉淀，形成很强的本地信任壁垒。因此05渠道不能只建立Company字段，必须记录Region/主要覆盖区域。

中国企业如果希望通过本土批发网络覆盖全国，更现实的思路往往不是找到“一家全国万能批发商”，而是逐步识别不同区域真正有影响力的网络。

## 6. 关系、合同和硬实力同时存在
大型跨国连锁更加标准化，采购人员可能轮换，企业、产品、品牌、供应链和合规硬实力的重要性更高。

西班牙本土批发采购集团则不同：产品必须成立、合同必须清晰，但本地关系和长期信任同样具有明显价值。一个可信任的西班牙本地连接人，可能显著缩短接触决策层和建立初始信任的时间。

## 7. 信用与账期
与本土老外B2B客户合作，应重视合同、账期、客户资信和信用保险。Leon实际业务中会通过Solunion等信用保险体系申请客户信用额度，不同客户根据资质获得不同额度。

因此智能体未来面对“这个西班牙客户能不能给账期”的问题，不能只讨论订单和利润，还应提醒企业评估：客户资信、保险额度、付款条件、逾期风险和法律追偿。

华人百货的信用逻辑与此不同，更多依赖关系、口碑和长期个人信用，因此不能机械套用同一模型。

## 8. 对智能体的规则
1. 05渠道必须按Region识别和推荐，避免把区域批发网络误判成全国渠道。
2. 必须识别中央仓采购与会员直采两种模式。
3. 报价和毛利计算必须预留返点、管理、广告、展会等合同费用。
4. 进入建议不仅看产品，还看本地关系、决策层触达、合同能力和信用风险。
5. 对第一次进入西班牙的中小企业，该渠道可能比大型跨国连锁更值得优先研究。
6. 未来逐一深挖Coferdroza、Coinfer及其他区域采购/批发网络，并建立Channel Card。
