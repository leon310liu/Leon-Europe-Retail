# Leon Knowledge System Workflow v1.0

## 目的
建立 Leon Knowledge System 的统一知识沉淀流程，确保商业知识、渠道卡、Leon View、案例和 Agent 知识资产按照统一规则进入 GitHub 知识库。

## 当 Leon 提出“沉淀”时

执行以下流程：

1. 判断知识类型

- Channel Card（渠道卡）
- Leon View（个人商业认知）
- Case Study（案例库）
- Agent Prompt / System Knowledge（智能体知识）
- Website / Content Asset（内容资产）

2. 写入对应目录

70-西班牙出海智能体：

- 渠道知识 → 02-西班牙渠道知识库
- Leon View → 03-Leon View知识库
- 案例 → 04-案例库
- Agent相关 → 05-Agent

3. 文件命名规则

统一格式：

名称-v版本号.md

例如：

Sinersis渠道卡-v1.0.md
Coferdroza渠道卡-v1.0.md

4. 内容标准

Channel Card 必须优先遵循：

- Channel Card Template v1.0
- 渠道分类体系
- Business Model 标签体系
- Vertical 标签体系

5. 版本管理

禁止直接覆盖重要知识资产。

版本升级：

v1.0 → v1.1 → v2.0

重大认知变化升级主版本。

6. 更新记录

每次重要沉淀需要记录：

- 更新时间
- 更新内容
- 新增 Leon View
- 影响范围

## 核心原则

GitHub作为Leon Knowledge System唯一知识源。

本地Desktop版本用于同步和工作。

GPT Agent知识库使用经过筛选后的正式知识文件。
