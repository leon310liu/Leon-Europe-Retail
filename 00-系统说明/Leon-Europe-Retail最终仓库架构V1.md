# Leon-Europe-Retail 最终仓库架构 V1

制定日期：2026-07-04

## 01 总原则

本仓库不是普通资料夹。

它是 Leon 欧洲零售研究、内容生产、个人IP、素材资产、商业系统和共创行动的长期操作系统。

以后所有目录分析、迁移和新增，必须以 GitHub main 分支当前结构为唯一依据。

本地临时目录不代表正式架构。

## 03 一级目录定位

### 00-系统说明

系统级规则目录。

用于存放：

- Agent宪法
- Agent团队框架
- 仓库架构说明
- 系统工具说明
- 目录迁移规则

### 01-Leon IP

Leon个人IP资产库。

合并原来的：

- `01-Leon个人`
- `Leon-IP`

用于沉淀：

- 个人履历与背书
- Leon观点库
- 个人故事库
- 视频号栏目资产
- 公众号栏目资产
- 白皮书资产
- SOP运营标准

原则：

`20-内容工厂` 负责生产内容。  
`01-Leon IP` 负责沉淀 Leon 的个人品牌资产。

### 02-后Action时代

Leon核心宏大叙事主题。

原 `02-主题研究` 升级为 `02-后Action时代`。

后Action时代不是普通视频栏目，而是 Leon 的核心思想母题。

建议下级目录：

```text
02-后Action时代
├── 00-后Action时代总论
├── 01-后Action时代认知战
├── 02-欧洲华人零售
├── 03-中国企业出海欧洲
├── 04-欧洲零售案例
├── 05-企业案例库
└── 06-国学商业认知
```

其中：

`06-国学商业认知` 用于沉淀孙子兵法、毛选、道德经、鬼谷子、王阳明等中国智慧与欧洲零售竞争的结合。

## 07 执行原则

1. 新增目录前，先判断属于哪个一级系统。
2. 不再新增英文 `tools` 一级目录。
3. 飞书公开知识库导出工具等工具类内容，归入 `00-系统说明/系统工具`。
4. 历史目录不直接删除，先迁移，再归档说明，最后废弃。
5. GitHub main 分支是唯一正式架构依据。
