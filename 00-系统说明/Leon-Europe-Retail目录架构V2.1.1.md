# Leon-Europe-Retail 目录架构 V2.1.1

制定日期：2026-08-07

状态：历史版本。

当前执行版本为：

`00-系统说明/Leon-Europe-Retail目录架构V2.2.md`

## 01 本轮目标

V2.1.1 是 V2.1 后的目录收尾版本。

目标：

- 删除已迁移的旧副本
- 去除重复入口
- 统一 ERCC 目录名称
- 明确 10-素材库定位
- 明确 02-内容主题 与 20-内容工厂边界
- 建立 CONTENT-ID 规则

本轮完成后，原则上冻结一级目录架构，不再频繁重构。

## 02 冻结一级目录

```text
Leon-Europe-Retail
├── 00-系统说明
├── 01-Leon个人
├── 02-内容主题
├── 10-素材库
├── 20-内容工厂
├── 30-视频包装
├── 40-ECR-OS欧洲华人百货操作系统
├── 50-ERCC-Action欧洲百货共创服务行动
├── 60-商业机会库
├── 90-归档与说明
├── README.md
└── AGENTS.md
```

## 03 唯一归属原则

一个文件只能有一个主要事实源。

其他地方通过链接引用。

如果历史目录已经迁移完成、没有独有内容、引用已修复，则删除旧副本。

Git 历史已经保留历史版本，不需要用旧目录永久保留重复文件。

## 04 归属判断规则

1. Leon是谁？→ `01-Leon个人`
2. Leon研究/讨论什么？→ `02-内容主题`
3. 未经加工的原始素材？→ `10-素材库`
4. 已经开始生产视频/公众号/其他内容？→ `20-内容工厂`
5. 封面、字幕、剪映、视觉包装？→ `30-视频包装`
6. ECR正式商业系统？→ `40-ECR-OS欧洲华人百货操作系统`
7. ERCC正式商业行动？→ `50-ERCC-Action欧洲百货共创服务行动`
8. 投资、合作、创业机会？→ `60-商业机会库`
9. 已经失效但具有历史价值？→ `90-归档与说明`

## 05 01-Leon个人

正式定位：Leon个人事实与IP身份数据库。

正式保留：

```text
01-Leon个人
├── README.md
└── LEON-IP-V2.md
```

不保存：

- SOP规则
- 视频号成品
- 公众号成品
- 白皮书项目
- ERCC正式方案
- 内容系列规则

如果未来个人履历、职业经历、核心能力等资料实际增长，再自然新增子目录。

## 06 02-内容主题

定位：知识资产 / 讲什么。

正式三个系列：

```text
02-内容主题
├── 01-后Action时代-欧洲华人百货
├── 02-深度出海元年
└── 03-重新开始
```

这里保存：

- 研究资料

## 07 20-内容工厂

定位：内容产品 / 做成什么。

这里保存：

- 视频号口播稿
- 公众号文章
- 内容生产标准
- 发布包
- 发布记录
- 复盘资料

边界示例：

“欧洲百货货架升级项目”

原始事实、故事背景、人物、数据、现场记录：

`02-内容主题/02-深度出海元年/案例库/`

最终视频口播：

`20-内容工厂/视频号/深度出海元年/`

公众号文章：

`20-内容工厂/公众号/深度出海元年/`

## 08 10-素材库

定位：Leon 平时随手拍、随手存、暂时还不知道以后具体怎么使用的原始素材池。

允许未分类。

例如：

- 照片
- 门店随拍
- 货架照片
- 视频片段
- 截图
- 录音
- 临时灵感
- 现场观察
- 聊天截图
- 行业新闻截图
- 旅行和生活素材

原则：

一个原始文件 + 多个索引引用。

如果未来某个素材被正式用于某个主题或内容，在对应主题或内容项目中建立引用或索引，尽量不要复制出多个完全相同文件。

## 09 ECR / ERCC / 商业机会边界

`40-ECR-OS欧洲华人百货操作系统`：欧洲华人百货升级落地系统，解决“怎么干”。

## 10 CONTENT-ID规则

统一规则文件：

`20-内容工厂/00-内容生产标准/CONTENT-ID规则.md`

当前系列代码：

```text
HA = 后Action时代-欧洲华人百货
SH = 深度出海元年
RS = 重新开始
```

同一主题内容在不同平台必须共享同一个 CONTENT-ID。

示例：

```text
CONTENT-ID: SH-004

视频号：SH-004-video.md
公众号：SH-004-article.md
知识卡：SH-004-card.md
数据复盘：SH-004-review.md
```

## 11 历史目录删除原则

历史目录不是因为“历史”就必须永久保留。

如果：

- 内容已经迁移
- 没有独有资料
- 引用已修复
- Git历史仍可追踪

则删除旧目录。

`90-归档与说明` 只用于：

- 重要迁移记录
- 架构变更记录
- 废弃原因说明
- 必要历史文档

不用于保留所有旧文件副本。
