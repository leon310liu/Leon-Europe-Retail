# CONTENT-ID 统一规则

版本：V2.2  
状态：正式启用

## 01 目标

为未来历史口播迁移、视频号、公众号、封面、复盘和发布记录建立统一内容编号。

同一思想资产在不同平台必须共享同一个 CONTENT-ID。

## 02 系列代码

当前三个正式系列：

```text
HA = 后Action时代-欧洲华人百货
SH = 深度出海元年
RS = 重新开始
```

## 03 编号格式

```text
HA-001
HA-002
HA-003

SH-001
SH-002
SH-003

RS-001
RS-002
RS-003
```

## 04 跨平台命名

同一主题内容在不同平台必须共享同一个 CONTENT-ID。

示例：

```text
CONTENT-ID: SH-004

视频号内容单元：20-内容工厂/01-视频号/深度出海元年/SH-004-标题/
公众号内容单元：20-内容工厂/02-公众号/深度出海元年/SH-004-标题/
单条复盘：对应内容单元/review.md
阶段复盘：20-内容工厂/03-数据复盘/
```

## 05 内容资产单元字段

每一条正式内容以后至少应该能关联：

- CONTENT-ID
- 系列
- 期数
- 标题
- 核心故事
- 核心观点
- 最终口播稿
- 公众号文章
- 封面标题
- 视频描述
- 评论区钩子
- 发布时间
- 视频数据
- 复盘结论

不要求所有字段一开始都有，但目录和命名必须支持以后逐步补齐。

## 06 存放规则

原始事实、故事背景、人物、数据、现场记录：

```text
02-内容主题/对应系列/
```

视频号内容成品：

```text
20-内容工厂/01-视频号/对应系列/CONTENT-ID-标题/
```

公众号内容成品：

```text
20-内容工厂/02-公众号/对应系列/CONTENT-ID-标题/
```

通用封面、字幕、剪映、视觉包装规则：

```text
Codex Skill：leon-cover-design-v1 / leon-video-script-v1
```

单条内容的封面、字幕、发布包、复盘和素材：

```text
对应内容单元/
```

## 07 禁止事项

- 不允许同一内容在不同平台使用不同编号。
- 不允许把原始事实复制成多个事实源。
- 不允许用日期替代 CONTENT-ID 作为主要识别方式。
- 不允许为了目录好看创建大量空目录。
- 不允许重新建立独立的知识卡库、脚本库、字幕库、封面库、视频项目库。
