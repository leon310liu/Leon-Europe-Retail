# 后Action时代 SVG固定母版

本目录存放后Action时代系列封面的唯一权威母版。

## 权威母版

- `后Action时代母版.svg`

该 SVG 文件由 Leon 确认为后Action时代系列固定母版。以后制作 012、013、014 等新一期封面时，不再重新设计，不再重新生成类似图片。

## LOCKED 固定内容

以下内容固定不变：

- 画布比例与尺寸
- 背景图片
- Leon人物图片、位置、尺寸、裁切方式
- 后Action时代系列 Logo
- 字体、字号、字重、颜色、描边、行距
- 黄色装饰、分割线、底部信息区
- 所有固定元素坐标

## VARIABLE 可变字段

每一期只允许修改三个字段：

- `issue_number`：期号数字
- `main_title`：主标题
- `subtitle`：副标题

## 使用原则

1. 不允许改 SVG 母版结构。
2. 不允许 AI 重绘人物或重新生成类似封面。
3. 不允许调整固定元素位置。
4. 如果标题过长，只允许在 `main_title` 内调整换行。
5. PNG 成品必须由该 SVG 母版导出。
6. 如果 SVG 文字已经转曲导致无法安全编辑，应先要求可编辑源文件，不得自行做近似版。
