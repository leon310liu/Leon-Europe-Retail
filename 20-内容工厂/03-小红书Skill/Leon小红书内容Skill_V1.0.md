# Leon小红书内容Skill V1.0

## 一、小红书定位

小红书不是视频号复制平台，而是Leon欧洲渠道个人品牌的搜索型知识资产库。

核心目标：
让未来有欧洲市场、中国品牌出海、欧洲渠道问题的人，通过搜索找到Leon。

定位：
欧洲渠道专家的搜索型知识资产库。


## 二、内容关系

采用一源三用模型：

视频号：建立Leon人物连接。

公众号：沉淀Leon思想资产。

小红书：积累搜索入口资产。

三者共享Leon知识体系，但不要求一稿三发。

## 四、小红书标题规则

标题必须包含搜索关键词。

公式：
身份/场景 + 问题 + 观点

避免：
泛情绪标题。

例如：
错误：疯狂进化的学习力

正确：
40岁创业者重新学习AI Agent，我发现学习力才是最大资产

5. 引导互动
