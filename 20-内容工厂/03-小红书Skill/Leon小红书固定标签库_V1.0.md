# Leon小红书固定标签库 V1.0

## 定位

小红书是 Leon 欧洲渠道个人品牌的搜索型知识资产库。

固定标签用于长期积累搜索权重，不建议每篇随意新增标签。

每篇发布时，从固定标签库中根据主题选择 3-5 个。
