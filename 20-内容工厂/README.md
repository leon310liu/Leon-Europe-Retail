# 20-内容工厂

## 定位

本目录负责已经进入生产流程的内容产品。

它回答：

内容做成什么。

这里不是 Leon 个人档案，不是原始素材库，也不是 ECR/ERCC 正式商业系统。

## 内容单元原则

同一条视频的核心资产尽量放在同一个内容单元中。

示例：

```text
20-内容工厂/01-视频号/后Action时代-欧洲华人百货/HA-006-不会聊天损失不止一个亿/
├── video.md
├── cover.md
├── publish.md
├── review.md
├── subtitle.srt
└── assets/
```

不要求每条内容一开始就具备所有文件。

但不再把同一条内容拆到“知识卡、脚本库、字幕库、封面库、视频项目库”等多个工序目录。

## 公众号结构

公众号不与视频号混在同一目录。

同一主题内容使用相同 CONTENT-ID。

```text
20-内容工厂/02-公众号/深度出海元年/SH-004-标题/
├── article.md
├── publish.md
└── assets/
```

## 数据复盘

`03-数据复盘` 只保存跨视频、跨系列、阶段性、总体性的数据分析。

单条视频复盘优先放在对应内容单元：

`review.md`

## 规则引用

短视频生产读取：

`20-内容工厂/00-内容规则/VIDEO-ENGINE-V2.md`

CONTENT-ID读取：

`20-内容工厂/00-内容规则/CONTENT-ID规则.md`

真实性边界读取：

`20-内容工厂/00-内容规则/真实性等级V2.md`

发布后复盘读取：

`20-内容工厂/00-内容规则/VIDEO-REVIEW.md`

视觉、字幕、剪映、封面读取：

`20-内容工厂/00-内容规则/视觉与剪辑规范/`

## 与 02-内容主题 的关系

`02-内容主题` 保存主题规则、研究资料、观点库、案例库。

`20-内容工厂` 保存已经进入生产流程的视频、公众号、发布包和复盘记录。

一句话：

`02-内容主题` = 知识资产 / 讲什么。

`20-内容工厂` = 内容产品 / 做成什么。

## 禁止新增工序库

V2.2 后不要再建立：

- 视频知识卡
- 口播稿
- 封面系统
- 数据卡库
- 深度文章
- 白皮书
- 视频剪辑标准
- 视频项目库
- 字幕库
- 脚本库

这些内容应进入具体内容单元、内容规则、数据复盘或内容主题。
