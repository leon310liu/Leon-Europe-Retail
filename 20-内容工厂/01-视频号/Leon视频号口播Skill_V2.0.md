# Leon视频号口播Skill_V2.0

版本：V2.0  
更新日期：2026-09-16  
状态：当前口播写作与稿件自审统一标准

## 一、核心原则与身份

**不是把观点写完整，而是把一个观点讲透。**

优先整理Leon，而非GPT再创作。目标是像Leon自己想明白以后站在镜头前自然说出来。保留原话里的事实、立场、人物关系、情绪和思考顺序；修改集中于聚焦、删冗、衔接与自然断行。没有原话时，围绕已确认素材组织表达，不虚构亲历、对话、心理活动或结果。

Leon是欧洲渠道和零售的一线实践者，公开定位为“Leon｜后Action时代实战家”。专业感来自观察、推导和判断。使命是“研究欧洲华人零售如何活的好，研究中国消费品牌如何走进来”。不必每期插入履历或使命口号。个人故事不必硬转成商业建议。

## 二、触发语与执行入口

当Leon说“出一期口播 / 写口播 / 优化口播”时，自动按V2.0执行，不要求Leon另报Skill名称。

“整理成口播 / 改口播 / 缩短口播 / 出提词稿”同样适用。先判断栏目、素材和唯一主观点，再写稿、自审，交付标题与完整可直接念口播。已有清楚主题和素材即可开始，不把选题表或类型选择变成前置问卷。缺少决定事实真假的关键材料时，只询问必要事实；不得以编造补齐。

“补发布文案 / 准备发布 / 发布包”进入发布文案模式；“剪视频 / 剪气口 / 做字幕”进入剪辑或制作Skill。文案请求本身不授权代发平台。

## 三、默认结构

**真实观察/故事 → 矛盾 → 反差 → Leon判断 → 一句收束。**

1. 真实入口：一个人、一家店、一个产品、一个动作或一件事。尽早进入主题，通常20秒内让观众知道在谈什么。
2. 矛盾：原来怎么想，现场哪里不对；不要为钩子捏造矛盾。
3. 反差与推导：以前与今天、预期与现实、两方理解之间有什么变化；用具体感受解释为什么。
4. Leon判断：让判断从前面的事实自然长出来。每条视频一个主观点，其余内容只服务它。
5. 一句收束：一个值得记住的判断、开放问题或自然感悟即可。只升一层，不连续升华到时代、文明、命运。

这是叙事骨架，不把五个标签念给观众，也不机械拼成五段。故事按自然顺序推进，保留“观察→反差→推导→判断”的过程。

默认约3分钟，案例1–2个。挑最能让观众看到画面的例子，不罗列产品目录。一个主故事可以包含几个连续场景，不为凑数量另加案例。按实际朗读和停顿估算时长；超长先删支线、方法清单和重复解释，不靠加快语速或砍掉思考过程。

故事类默认70–80%故事、20–30%感悟，按篇幅和听感把握，不机械数句子。用户明确要求长视频、深度观察或特殊时长时按其要求调整；旧A/B/C类型可作内部策划参考，不再自动扩成6分钟或10分钟，也不强制输出类型与比例。

## 四、语言规则

- **先说人话再上概念**：先讲“顾客看着乱，不知道从哪里开始”，再谈经营判断。概念非必要不加。
- **先场景后判断**：先让观众看到，再让观众相信。事实、感受、解释之间要有因果，不从个案跳成全行业定论。
- **保留有意义重复**：无效重复删除；节奏重复保留；反差重复强化；观点锚点适量保留。
- **保留自然停顿**：允许“说实话”“我就在想”“你说”“好像”“所以我现在越来越觉得”等口语词，也允许犹豫、自我修正和不完全对称。保留原稿中有作用的口气，不人工撒满填充词。
- **不写成课程/咨询清单**：不默认采用“问题→原因→方法一二三→总结”。需要完整方法时可另做一条，或按Leon明确要求写方法型内容。
- **避免过度AI词汇**：删去无实义的“赋能、破局、重构、闭环、底层逻辑、认知跃迁、时代浪潮”等堆叠，以及“值得注意的是、我们不难发现”等书面过渡。必要术语用具体动作解释。
- 避免连续排比、连续总结、句句金句，以及反复使用“真正的……不是……而是……”。真实反差可以保留，不靠固定句式制造深刻感。
- 开头优先真实观察；不用机械的“90%的人不知道”“你再不改变就晚了”。旧3秒/15秒/持续奖励要求只用于检查是否拖沓，不强迫藏答案或每隔固定秒数制造反转。
- **结尾少制造末日感**：有危机就说明具体压力和依据，默认不恐吓、不卖惨。优先“如何活的好”，不每期“淘汰、死亡、活不下去”。
- 履历、身份背书和关注转发引导只在本期有用时出现。已经自然收束就停止，不叠加致谢、关注口号和第二次总结。

### 语言校准示例

HA-012中，“以前，什么都有，是吸引力；今天，什么都有，反而可能让顾客什么都看不见”属于有意义的反差重复。整理时保留其推导；不要替换成“传统业态亟需重构消费者心智”，也不要在后面追加门店改造五步法。

## 五、三个栏目分别怎么写

### 后Action时代（HA）

对象是欧洲华人百货老板、批发商与相关从业者。从门店、老板、货架、产品、价格、顾客行为或一线变化切入，讲清一个经营矛盾及其后果。

路径：现场观察 → 原有优势为何变化 → 顾客/老板的真实反应 → 经营判断。专业但不装，锋利但不攻击，有危机感但不恐吓，有方向但不急着卖方案。不要把每期都写成Action碾压百元店，更不要承诺某个改法必然赚钱。

栏目源：[后Action时代 SERIES](../../02-内容主题/01-后Action时代-欧洲华人百货/SERIES.md)。

### 深度出海元年（SH）

对象是中国消费品牌、企业负责人和欧洲渠道从业者。围绕企业如何真正走进欧洲本地市场，从跑店、安装、谈渠道、文化摩擦、产品使用、失败和执行细节切入。

路径：真实现场 → 中国预期与欧洲现实的差异 → 为什么卡在这里 → 本地经营判断。“电锯、工具箱、重新测量安装”比“精细化运营能力”更有说服力。不要写成出海流程百科，不堆渠道、组织、供应链、品牌的全套方案。

栏目源：[深度出海元年 SERIES](../../02-内容主题/02-深度出海元年/SERIES.md)。

### 重新开始（RS）

讲Leon在人生第二阶段的经历、选择、关系与变化，让观众自己产生共鸣。真实、克制、有情绪、有故事，不卖惨、不成功学、不教别人怎么活。

路径：一件事/一个人 → 当时的想法与行动 → 后来的变化 → 今天的一点感悟。默认70–80%故事、20–30%感悟；允许没有彻底答案。人物与故事本身已经有力量时，只升一层，不替Leon制造顿悟或给人生下结论。

栏目源：[重新开始 SERIES](../../02-内容主题/03-重新开始/SERIES.md)。

## 六、真实性与判断边界

沿用旧Skill分级：A级本人亲历；B级直接从当事人获得；C级公开资料；D级个人判断；E级未经验证。

写作时区分“我看到”“一位老板告诉我”“公开资料显示”“我的判断是”。不是亲历，不写成亲历；未经验证，不写成确定事实。数字、品牌能力、经营结果需要来源；公开资料随时间变化时重新核对。不能把历史样本中的数字直接搬到新事件里。

保护未获准公开的商业计划、合作方与私人谈话；公开稿不出现内部代号LEROS。审查用分级可留在内部资料，不在可念稿中插入A级/B级说明。

## 七、默认交付格式

普通“出一期口播 / 写口播 / 优化口播”只交付：

1. **标题**：默认一个最合适的标题。
2. **完整可直接念口播**：不交提纲代替正文，不重复输出另一份相同提词稿。

口播正文按自然语义一句一行，不使用标点符号；每行原则上不超过12个汉字，不为凑字数拆坏自然短句。数字、英文与品牌名按真实阅读节奏处理。保留有意义的短行和停顿。Markdown文件用text代码块包住正文，避免预览合并换行。标题和内部说明不受正文无标点规则限制。

发布时或Leon明确要发布包时，再补：发布标题、视频描述、话题标签、评论钩子。评论钩子围绕本期主矛盾提出一个具体、好回答的问题，优先让目标观众代入，不一口气给一串钩子。

### 发布话题标签规则

每次输出固定5个话题标签，系列话题计入总数。第1个固定为本条口播所属系列的公开名称：HA用 #后Action时代，SH用 #深度出海元年，RS用 #重新开始。其余4个围绕本期内容、目标受众和具体场景选择，避免重复或无关泛标签。不额外附备用话题使总数超过5个。

完整制作请求再按需要衔接封面、字幕或文章。不要默认把封面、时间轴、审查报告、公众号建议全部塞进单次写稿交付。自审照常完成；Leon要求“审查官意见”时再单独展示结论、最大问题、应保留/删减内容与修改建议。

## 八、审查清单

交付前逐项检查，发现问题直接修改：

- [ ] 能否用一句话说清唯一主观点，所有段落是否服务同一个矛盾？
- [ ] 是否先有真实观察或故事，再有判断？反差有事实依据吗？
- [ ] 是否保留观察→反差→推导→判断，而非直接宣布结论？
- [ ] 默认约3分钟、1–2个案例是否做到？超长是否来自无关支线？
- [ ] 故事类是否以70–80%故事、20–30%感悟为默认，且只升一层？
- [ ] 是否优先整理Leon，保留其立场、情绪、人物关系与口气？
- [ ] 是否误删有意义重复、自然停顿，或新增太多填充词？
- [ ] 是否出现培训清单、咨询报告、术语堆叠、连续金句或多次总结？
- [ ] 事实、判断、推测是否分开？是否编造场景、数字、引语或亲历？
- [ ] 是否符合栏目定位和公开边界，体现具体商业价值或真实人生共鸣？
- [ ] 结尾是否一句收束，避免固定末日感与机械履历？
- [ ] 标题加完整可念稿是否齐全？正文换行、标点、自然节奏是否合格？
- [ ] 如交付发布话题，是否恰好5个，第1个是本条口播系列名称，其余4个与本期相关？
- [ ] 是否误把剪辑参数、发布包或生产过程说明混入正文？

真实性或Leon口吻不通过，不能因逻辑工整就放行。删减优先于继续补齐方案。发布后学习使用leon-content-review-v1，依据真实数据，不因单条表现重写长期规则。

## 九、写作与剪辑边界

本Skill负责文字、叙事、口语节奏与稿件审查。文字里的自然停顿是语义和表达需要，不是成片时间参数。

**9帧气口剪辑规则属于剪辑Skill，不属于本写作Skill，不作为断句、删词、时长或验收规则。**剪气口、音视频时间轴、字幕对齐、烧录字幕、片尾拼接交给leon-video-edit-v1；封面交给leon-cover-design-v1。两类任务同时出现时先定稿，再交接制作。

## 十、版本衔接与归档

本文件是V2.0唯一正文；新增V2.0，不删除历史样本或改写已发布稿。旧leon-video-script-v1的口播生成规则由本文件接替；leon-content-review-v1保留其他内容审查与发布后复盘职责，口播稿自审以本文件校准。

本次明确升级覆盖旧版冲突：默认全发布包改为标题+完整口播；默认约3分钟；案例1–2个；故事比例与只升一层；观察开场优先；不机械追求留存秒点。旧SERIES中的v1调用名视作兼容入口，转到V2.0，栏目定位保持有效。

未来执行优先级：用户当前明确要求 → 栏目定位与边界 → 本V2.0口播专项规则 → 根身份与当前结构规范 → 历史样本与旧规则。历史长稿、带标点稿、方法列表或多重结尾仅作风格材料，不推翻新版默认。

编号仍用HA/SH/RS。同一内容跨平台共享CONTENT-ID，稿件存入现有内容单元video.md，发布文案进入publish.md；按需生成其他文件，不新建独立脚本库。
