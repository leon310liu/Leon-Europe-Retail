# 02-内容主题

## 定位

本目录是 Leon 公开内容主题体系。

它回答：

Leon 研究、讨论和持续输出什么。

这里不是 Leon 个人事实档案，不存放原始素材，不存放已经进入生产流程的视频或公众号成品，也不存放 ECR/ERCC 正式商业系统。

## 三个正式内容系列

```text
02-内容主题
├── 01-后Action时代-欧洲华人百货
├── 02-深度出海元年
└── 03-重新开始
```

## 唯一归属原则

一个内容只能有一个主要归属位置。

其他地方通过链接引用。

不要复制同一类内容到多个一级目录。

## 归属判断

1. Leon是谁？→ `01-Leon个人`
2. Leon研究/讨论什么？→ `02-内容主题`
3. 未加工原始素材？→ `10-素材库`
4. 已进入视频/公众号生产？→ `20-内容工厂`
5. 封面、字幕、剪映、视觉包装？→ `30-视频包装`
6. ECR正式商业系统？→ `40-ECR-OS欧洲华人百货操作系统`
7. ERCC正式商业行动？→ `50-ERCC-Action欧洲百货共创服务行动`
8. 投资、合作、创业机会？→ `60-商业机会库`
9. 失效但有历史价值？→ `90-归档与说明`
