# 第四板块｜战略路径与执行

> 上级框架：[Leon 2030人生事业战略地图 V2.0](../00-顶层战略框架/Leon-2030人生事业战略地图-V2.0.md)

本板块回答：Leon如何从真实现状出发，配置资源、建设能力、跨过关键阶段，最终实现2030目标。

它不是独立于前三板块的新战略，而是把01—09定义的方向、事业和个人成长要求转化为可推进、可验证、可复盘的现实路径。

## 运行关系

```text
01—09｜定义方向、事业和个人成长要求
        ↓
10｜建立现状基线、识别关键差距与主要矛盾
        ↓
11｜确定阶段划分、先后顺序与结果门槛
        ↓
12｜形成年度重点、90天行动和战略复盘
        ↓
返回01—11动态校准
```

## 模块10｜现状诊断与差距

输入来自01—09及当前真实事实。输出包括：现状基线、已有优势、现实约束、关键差距和主要矛盾。

必须分开记录：
- **已知事实**：有数据、结果或可靠记录支持；
- **战略判断**：Leon基于经验形成、但仍需持续验证；
- **待验证假设**：必须通过客户、市场或行动结果确认。

不能把希望写成现状，把关系线索写成可调用资源，或者把准备行动写成已经具备的能力。

## 模块11｜阶段路径与里程碑

以模块10确认的关键差距和主要矛盾为输入。输出包括：阶段划分、先后顺序、关键任务、资源与能力要求、里程碑和结果门槛。

路径规则：
1. 每个阶段突出主要矛盾，避免同时建设全部事业板块。
2. 前一阶段结果必须为后一阶段创造必要条件。
3. 结果门槛描述状态变化，不以活动数量代替结果。
4. 资源只有在可调用、适配当前阶段并能产生结果时，才构成战略资源。
5. 能力可以自己建设、通过合作获得或外部购买。
6. 早期路径优先低投入、可逆、能够快速获得真实反馈的验证方式。

## 模块12｜年度行动与战略复盘

只承接模块11确认的当前阶段。输出包括：年度重点、90天行动、指标、停止条件、复盘和下一轮校准。

行动与复盘规则：
1. 年度和90天行动必须来自当前阶段，不能从2030愿景直接生成任务。
2. 行动数量服从战略重点，避免用忙碌掩盖核心问题没有进展。
3. 月度复盘关注领先指标，季度复盘关注结果门槛和路径假设。
4. 未通过阶段门槛时，不因时间到点自动进入下一阶段。
5. 真实结果与原判断冲突时，以真实结果为准，返回模块10、11或必要的01—09校准。

## 当前边界

本板块当前确认模块10—12的结构、输入、输出和运行规则。具体诊断、阶段路径、年度计划和90天行动，必须以真实事实和Leon确认结果为基础逐步沉淀，不虚构、不预填。
