# 欧洲本土品牌资源库

> 归属：Leon 2030人生事业战略地图 V2.0 → 02｜事业系统 → 06｜资源体系 → R10｜资本与战略合作资源库 → R10.06｜战略合作伙伴
> 定位：沉淀欧洲本土消费品牌、家电品牌及潜在需求方企业档案。

## 一、为什么不放 R01

R01｜中国企业与产品资源库只收录中国品牌、工厂、OEM/ODM 与中国产品资源。欧洲本土品牌不是中国供应端，因此不得放入 R01。

欧洲本土品牌对 Leon 的战略价值主要在于：

1. 作为欧洲市场需求端与品牌合作对象；
2. 识别其产品结构、渠道能力与供应链需求；
3. 为未来“欧洲品牌需求 → Leon → 中国 OEM/ODM / 供应链”反向业务建立企业数据库；
4. 研究欧洲本土品牌如何做产品、本地化、渠道与售后，为 China Tech 提供市场参照。

因此当前统一归入 R10.06｜战略合作伙伴 → 欧洲本土品牌。

## 二、资源等级规则

- 仅完成公开资料研究、尚未建立联系：L1｜已研究。
- 与明确联系人建立双向沟通后：L2｜已建立联系。
- 发生样品、供应链、渠道或小规模项目验证后，再按 Resource Map 规则升级。

品牌知名度、销售规模、市场份额均不能代替 Leon Resource Level。

## 四、后续建议扩展对象

后续可继续研究并按同一模板建档：Orbegozo、Ufesa、Jata、Princess（西班牙市场）、Grunkel、Sogo、Fagor 品牌体系及其他西班牙本土/伊比利亚消费家电品牌。

## 五、统一治理

每张品牌卡至少区分：

- 公开事实；
- Leon 判断；
- 待验证事项；
- Resource Level 与关系证据；
- 最近验证日期与来源。

不得把“品牌使用中国供应链”作为默认事实；只有取得公司、产品、海关、认证、供应商或其他可靠证据后才能记录具体供应链关系。
