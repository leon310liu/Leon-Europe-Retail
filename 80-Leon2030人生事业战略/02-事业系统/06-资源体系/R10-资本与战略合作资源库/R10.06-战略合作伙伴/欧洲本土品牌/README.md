# 欧洲本土品牌资源库

> 归属：Leon 2030人生事业战略地图 V2.0 → 02｜事业系统 → 06｜资源体系 → R10｜资本与战略合作资源库 → R10.06｜战略合作伙伴
> 定位：沉淀欧洲本土消费品牌、家电品牌及潜在需求方企业档案。

## 一、战略价值

R01｜中国企业与产品资源库只收录中国品牌、工厂、OEM/ODM 与中国产品资源。欧洲本土品牌不是中国供应端，因此不放入 R01。

欧洲本土品牌对 Leon 的价值是：

1. 作为欧洲市场需求端与品牌合作对象；
2. 识别其产品结构、渠道能力与供应链需求；
3. 为“欧洲品牌需求 → Leon → 中国 OEM/ODM / 供应链”反向业务建立企业数据库；
4. 研究欧洲本土品牌的产品、渠道、售后、定价和新品节奏，为 China Tech 提供参照。

## 二、品牌卡固定研究字段

以后每个品牌档案必须至少回答：

1. **历史**：创立时间、关键并购/控制权变化、品牌发展阶段；
2. **定位**：目标消费者、价位、品牌心智、核心竞争方式；
3. **实力**：集团/公司规模、国际覆盖、团队、研发、制造、仓储、渠道等；
4. **销售额**：优先记录最新可核实数字，并注明年份、法律主体和口径；无可靠数字则明确“未公开/待验证”；
5. **品类**：当前核心产品线及强势品类；
6. **最新动态**：近12–18个月新品、并购、扩产、渠道、组织和国际化动作；
7. **Leon View**：它对 China Tech、欧洲渠道研究和反向供应链业务的价值；
8. **待验证**：采购、供应链、OEM/ODM、决策人、渠道销售结构等。

销售额不得混淆“单品牌 / 法律主体 / 集团合并 / 西班牙市场 / 全球”不同口径。商业数据库冲突时保留冲突，不强行选数。

## 四、下一批候选

后续优先继续研究：Fagor 品牌体系、Create / Ikohs、Mellerware Spain 相关体系、Nevir，以及在西班牙有显著本地运营能力的伊比利亚品牌。

Princess 等非西班牙起源品牌可作为“西班牙市场重要欧洲品牌”另设标签，不应误写为西班牙本土品牌。

## 五、资源等级规则

- 仅完成公开资料研究：L1｜已研究。
- 与明确联系人建立双向沟通：L2｜已建立联系。
- 发生样品、供应链、渠道或小规模项目验证后，再按 Resource Map 规则升级。

品牌知名度、销售规模、市场份额均不能代替 Leon Resource Level。

## 六、统一治理

每张品牌卡必须区分：公开事实、第三方数据库/媒体数据、Leon判断、待验证事项。

不得把“品牌使用中国供应链”作为默认事实；只有取得公司、产品、认证、海关、供应商或其他可靠证据后才能记录具体供应链关系。
