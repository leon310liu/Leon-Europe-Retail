## 欧洲本土品牌归档规则

欧洲本土消费品牌、家电品牌和潜在需求方企业不归入 R01。R01 只管理中国品牌、工厂、OEM/ODM 与中国产品资源。

欧洲本土品牌作为未来“欧洲品牌需求 → Leon → 中国 OEM/ODM / 供应链”反向业务的需求方和战略合作对象，统一归入：

`R10｜资本与战略合作资源库 → R10.06｜战略合作伙伴 → 欧洲本土品牌`

当前首批已建立 Cecotec、Taurus、Solac、FM Calefacción 档案，均以公开研究状态 L1 起步；未建立联系前不得提升为 L2。
