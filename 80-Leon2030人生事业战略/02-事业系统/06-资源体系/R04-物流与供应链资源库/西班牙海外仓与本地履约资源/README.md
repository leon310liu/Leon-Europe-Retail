### 评分规则

1. 每项必须同时有“能力描述 + 证据 / 来源 + 评分或待验证”。
2. “待验证”不计入可确认分；不因品牌规模、行业名气或关联公司能力而推定。
3. 得分表示“当前证据下的该项覆盖度”，不表示服务质量、价格竞争力或实战交付结果。
4. 信息证据状态依次为：`公开资料` → `已沟通确认` → `已报价` → `已试单` → `已合作验证`。
5. 与资源等级的最低映射：公开资料研究完成可达 L1；已沟通确认可达 L2；报价本身不自动升级；已试单且核心能力通过可达 L3；已付费合作并复盘可达 L4；多次合作稳定且有共建意愿才可达 L5。

## 四、当前判断边界

- ICP 和 Arvato 的公开 China Tech 能力链最完整，但两者都尚未验证对中小中国品牌的准入和商务条件。
- FM Logistic 的 B2B + B2C + 逆向物流证据强，但不能把“售后运营”直接等同于电子产品故障检测、维修、备件或 DOA 处理。
- 千象盒子的中文衔接、西班牙仓、B2C 和尾程异常西语客服可确认；其他售后能力仍需询价和现场验证。
- ESPOST 的可检索官方资料有限，当前分数主要反映证据缺口，不反映实际能力上限。
