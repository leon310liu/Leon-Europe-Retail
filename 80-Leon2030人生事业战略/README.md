## 归档与治理原则

- 当前总框架只保留四大板块、十二个模块，统一按01—12顺序管理。
- 除非Leon明确确认发生重大战略变化，否则不得新增、拆分、合并或重排顶层模块。
- 复杂内容一律下沉到对应模块内部，不新建平行顶层体系。
- 一个内容只保留一个主归属，其他位置通过链接引用，避免重复沉淀。
- 06只管理“资源”，07只管理“能力”；认识谁与会不会做必须分开。
- 10负责诊断、11负责路径、12负责行动与复盘，不得混写。
- 资源地图及后续十大资源库统一归属于“第二板块｜事业系统 → 06｜资源体系”。
- V1.0作为历史版本保留，不再作为新增内容的上级框架。

## 沉淀完成标准

正式沉淀不以“文件已写入”为完成，而以以下四项全部通过为准：
1. 目录结构与最终战略框架一致；
2. 内容归属与模块边界一致；
3. README/导航入口同步更新；
4. 写入后完成目录与关键文件回读巡检。
