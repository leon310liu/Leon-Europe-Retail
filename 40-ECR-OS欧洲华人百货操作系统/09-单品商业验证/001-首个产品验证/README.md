# 001-首个产品验证

## 项目目标

这是 Leon 一人公司模式下，第一个从产品机会到真实门店销售的完整验证项目。

我们不预设最终一定是某一个具体产品。产品正式锁定之前，以“001-首个产品”管理。

## 成功不是“把货铺进去”

本项目真正要验证的是一条完整链路：

中国供应端 → 西班牙落地 → 华人百货门店 → 终端展示与内容 → 消费者购买 → 数据反馈 → 补货

只有消费者购买和后续补货出现，才说明链路开始跑通。

## 当前阶段

**阶段 0：项目启动 / 产品候选确认**

当前最重要的问题只有一个：

> 第一款产品到底选什么，以及为什么值得用它做第一次真实测试？

## 项目工作区

后续资料统一按以下结构建立：

- `01-产品定义`
- `02-供应商与合作模式`
- `03-市场与竞品`
- `04-合规与风险`
- `05-价格与利润模型`
- `06-种子门店`
- `07-首批测试方案`
- `08-终端营销物料`
- `09-产品落地页与二维码`
- `10-销售与扫码数据`
- `11-门店与消费者反馈`
- `12-项目复盘`

## 当前不做

为了避免系统建设取代真实业务，本阶段暂不优先：

- 开发复杂 CRM
- 建大型 ERP
- 建完整共创平台
- 大规模铺货
- 一次同时测试多个品类
- 为尚未发生的业务提前开发大量自动化

## 第一关

先完成首个产品的候选评估和 GO / NO-GO 判断。

完成后再进入供应商、价格、合规和种子门店阶段。
