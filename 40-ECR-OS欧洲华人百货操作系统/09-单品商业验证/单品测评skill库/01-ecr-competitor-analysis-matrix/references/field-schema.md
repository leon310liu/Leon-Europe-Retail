# 竞品分析矩阵字段字典

## 1. 产品身份

- 竞品编号；竞品图片；图片来源；图片获取日期
- 品牌；完整型号；产品系列；产品类别；市场定位；目标用户
- 上市状态；上市时间；品牌国家；制造地
- 西班牙官方链接；西班牙主要销售渠道；数据核查日期

图片必须对应准确型号。优先官方正面图或白底图。

## 2. 价格

- 官方建议零售价；官方当前售价；主要渠道最低价；主要渠道常见价
- 促销前价格；折扣率；含税/不含税；配置对应价格；保修年限
- 价格核查日期；价格来源；30/90天价格区间
- 价格稳定性；折算不含VAT价格

自动计算：`折扣率=(原价-现价)/原价`；西班牙标准税率场景下 `不含VAT价格=含税价/1.21`。税率变化时以核查日官方规则为准。

## 3. 硬参数

### 3.1 通用物理与物流字段

- 产品尺寸（长×宽×高，mm）；产品净重（g）
- 包装尺寸（长×宽×高，mm）；单台包装毛重（g/kg）；单台包装体积
- 包装内容物；外箱装箱数；外箱尺寸；外箱毛重
- 颜色/版本；材质；电线长度；插头规格

自动计算：`单台包装体积=长×宽×高`。记录尺寸时注明是否含突出部件、线材或附件。

### 3.2 品类专用字段

按目标品类建立字段组。吹风机默认使用：

- 电机类型；转速；额定功率；电压/频率；风速；风量；噪音
- 噪音测试距离与标准；温度档位与范围；风速档位；冷风模式
- 温控方式与检测频率；传感器类型；距离感应；湿度感应
- 自动调温；自动调速；离子/Plasma类型与浓度
- 显示屏；操作方式；记忆；放下暂停；风嘴识别
- 附件数量与清单；磁吸附件；可拆洗滤网；电机寿命；过热保护

其他品类保留通用字段并替换本组。参数未知不得推测。

## 4. 消费者价值

- 核心一句话卖点
- 快干；护发；头皮保护；减少毛躁；光泽
- 轻量与握持；噪音体验；操作便利；造型能力；设计质感
- 30秒可演示性；核心价值可感知程度
- 购买理由；不购买理由；适合人群；不适合人群
- 高频正面评价；高频负面评价

每项评分或判断都附一句证据。使用“技术功能 → 消费者结果”表达，不照抄营销术语。

## 5. 商业与风险

- 品牌认知度；品牌信任度；西班牙渠道覆盖；售后服务能力
- 评论数量；平均评分；高频质量问题；高频退货原因
- 促销强度；价格稳定性；Bazar渠道可获得性与陈列适配度
- 体验机需求；防盗展示难度；店员讲解难度；预计售后风险
- 合规风险；技术/IP风险；营销主张风险
- 目标产品相对优势；相对劣势；可攻击位置；应避免位置
- 对ECR单品验证的启示

## 6. 证据等级与来源台账

| 等级 | 定义 | 用途 |
|---|---|---|
| A | 官方技术文件、说明书、测试报告、法规文件 | 正式判断 |
| B | 品牌官网或官方西班牙商店 | 型号、功能、价格 |
| C | 西班牙主流授权零售商 | 渠道价格、库存状态 |
| D | 用户评论、专业媒体、第三方实测 | 体验与问题线索 |
| E | 供应商PPT、招商资料、自述 | 待验证主张 |
| F | 论坛、非授权卖家、搜索摘要 | 研究线索 |
| U | 未找到证据 | 不得推断 |

每条关键数据保存：竞品编号、字段名、数据值、证据等级、来源名称、链接、核查日期、原文/位置、冲突状态、最终采用值、采用理由。
