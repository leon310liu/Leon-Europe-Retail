## 2. Geographic distribution footprint

### PUBLIC FACT

Sunmarket 官方称其向整个 `Espacio Económico Europeo (EEE)` 分销，并使用西班牙语、英语、葡萄牙语、法语、意大利语和德语六种语言服务客户。

## 6. AI terminology boundary

### PUBLIC FACT

该产品公开使用 `Ai-Sensor` 命名，且能确认的功能是：

1. 识别连接的附件；
2. 根据附件自动调整温度；
3. 根据附件自动调整风速；
4. 提供头皮过热保护。

### TO VERIFY

当前公开材料不足以证明：

- 使用 machine learning model；
- 使用 NPU；
- 使用 camera / computer vision；
- 使用 ToF 或其他距离传感器；
- 根据发质自主识别头发类型；
- 根据环境湿度或头发湿度运行 AI model。

因此本卡不把 `Ai-Sensor` 扩写成未被公开资料证明的算法型 AI。
