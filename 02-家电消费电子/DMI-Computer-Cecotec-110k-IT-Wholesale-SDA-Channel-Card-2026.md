## 4. 采购/下游结构边界

### PUBLIC FACT

DMI公开表示自己与140+制造商拥有分销协议，并拥有8,500+参考SKU；其客户类型覆盖IT自由渠道、e-tailer/连锁门店、大型零售，同时国际客户页还明确列出Buying Groups。

### INFERENCE

公开资料支持以下“可研究路径”，但这不是对具体订单关系的确认：

`品牌/制造商 → DMI B2B分销体系 → IT门店 / E-Tailer / 连锁店 / Buying Group / Large Distribution → 终端消费者`

DMI目录中110k吹风机的存在，说明高速个人护理电器已经进入传统IT/科技批发基础设施。

### 禁止推断

不能仅凭DMI目录存在推导：
- 某一具体Milar/Tien21/Expert/MediaMarkt/Carrefour等零售商从DMI采购该SKU
- DMI是Cecotec独家总代
- DMI对Cecotec的MOQ、返点、账期、采购价、毛利
- DMI承担该SKU的进口主体角色
- 某个Buying Group已经采购这些吹风机

这些全部保持 `TO VERIFY`。

## 7. 数据冲突 / 过期风险治理

### CONFLICT A — 15,000 m² vs 17,000 m²

DMI西班牙“Sobre DMI”页面当前写Madrid总部设施总面积15,000 m²；国际注册页英文介绍写17,000 m² warehouse。

处理：
`OFFICIAL PAGE SCOPE/DATE CONFLICT — 15,000 m² vs 17,000 m² — TO VERIFY current logistics footprint`

不得自行选一个数字作为唯一最新事实。

### CONFLICT B — 5,000 references / 100 manufacturers vs 8,500 references / 140+ manufacturers

DMI部分官网入口/搜索页面仍显示“5,000+ references / 100+ manufacturers”旧口径；当前`Sobre DMI`页面则写140+ manufacturers、8,500+ references。

处理：
- 当前公司介绍页优先记录：140+ manufacturers / 8,500+ references
- 老页面数字标记为 `STALE/LEGACY WEBSITE COPY`，但除非DMI明确给发布日期，不把差异解释为特定年份增长率

来源：
- https://www.dmi.es/empresa/sobre-dmi/
- https://www.dmi.es/
