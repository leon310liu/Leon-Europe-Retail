## 1. 核心公开事实

### 1.1 110k 产品事实
Beardburys 官方当前公开 THUNDER 专业吹风机，规格包括：
- 数字 Brushless 无刷电机
- 110,000 RPM
- 2000–2200 W
- 82 m³/h 风量
- 450 g
- 3 m 专业电源线
- 离子技术
- 每45小时通过反向气流进行自动清洁

Beardburys 官方将该产品定位为面向 Barber Shop / Salon 的高强度专业工具。

Source: https://beardburys.com/es/afeitadoras-y-recortadoras/secador-profesional-thunder-351

### 1.2 专业客户准入机制
Beardburys 官方“Área Profesional”公开了专业账户准入：
- 可申请主体：Peluquería、Barbería、Salón de Belleza、Academia、Tienda de distribución de productos de belleza 等；
- 需要证明专业身份，可提交 Alta IAE、Modelo 036 或最近一期 autónomo 缴费证明等；
- 官方称资料提交后通常在少于24个工作小时内完成专业账户开通；
- 专业账户可获得专业折扣，并配套培训、顾问支持、品牌/技术/业务培训等。

Source: https://beardburys.com/es/content/area-profesional-8

## 2. 上游主体与品牌结构
Carobels 官方说明：
- Carobels 是西班牙家族企业，拥有35年以上专业美发/化妆品分销与零售经验；
- 近年来同时进行自有品牌的创建、生产和商业化；
- 总部位于 León；
- Beardburys 是其品牌体系中的专业男士护理/Barber品牌之一。

Source: https://www.carobels.com/es/carobels/empresa/1

专业行业媒体 Interempresas / PlanetLook 2024 报道称，Beardburys 为 Carobels 旗下品牌，并称其已进入西班牙及40多个国家。该“40+国家”属于第三方行业媒体口径，不等同于审计或官方当期覆盖数据。

Source: https://www.interempresas.net/Peluqueria/543784-Beardburys-La-marca-mas-canalla-de-cuidado-masculino.html

## 3. Carobels 的分销商/批发商体系
Carobels 官方单独设置“Distribuidores / Mayoristas”合作入口，并公开：
- 面向专业美发与化妆品 distributor / wholesaler；
- Carobels 自称为部分产品的制造商，同时拥有国际供应商；
- 可提供定制化商业方案、促销物料支持、直接顾问支持；
- 在满足公司条件时，可以给予区域独家（exclusividad）；
- 分销商被官方描述为其业务与成功的重要组成部分。

Source: https://www.carobels.com/es/carobels/5-oportunidades-de-negocio-c2bftrabajamos/distribuidores-mayoristas/26

## 4. 可确认的渠道结构
基于上述公开事实，可以确认 Beardburys / Carobels 同时存在至少两类专业渠道入口：

A. 直接专业账户：
Carobels / Beardburys → Barbería / Peluquería / Salón / Academia / Beauty distributor shop

B. 分销商体系：
Carobels / Beardburys → 区域/专业 Distribuidor-Mayorista → Barbería / Peluquería / Beauty retail / Professional customer

这里的箭头仅表达公开可见的渠道角色关系，不代表每一笔 THUNDER 订单必然走同一采购链。

## 5. 对001知识库的价值（事实层 + 推断层分离）

### PUBLIC FACT
- 西班牙本土专业Barber品牌已经公开销售110k RPM brushless专业吹风机；
- 该品牌不仅有DTC/专业账户，还公开建设 distributor / wholesaler 合作体系；
- 专业账户准入要求验证经营/职业身份，并非完全开放式普通消费者批发账户。

### INFERENCE — clearly marked
这说明110k高速吹风机在西班牙已进入“专业Barber品牌 + 专业账户 + 区域/行业分销商”这一垂直渠道组合，而不仅是大众家电、IT批发或Marketplace渠道。

这是一项基于公开渠道结构和公开SKU的渠道趋势推断；不代表已知 THUNDER 的销量、铺货率或市场份额。
