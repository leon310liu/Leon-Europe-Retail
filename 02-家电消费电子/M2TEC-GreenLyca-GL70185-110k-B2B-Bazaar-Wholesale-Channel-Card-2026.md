## 3. 对“华人百货 / bazar上游”研究的价值

M2TEC 官网在多个吹风机SKU描述中直接写明“Producto disponible para venta mayorista B2B, tiendas, bazares y ecommerce”，且公司首页把 bazares 明确列为客户类型。这是目前公开资料中少见、可以直接证明“西班牙B2B科技/杂货批发商将个护电器供给 bazar 客户”的事实样本。

公开事实层面的渠道链可以记录为：

品牌/自有品牌货盘 → M2TEC西班牙B2B批发库存 → tiendas / bazares / eCommerce / distribuidores / franquicias / dropshippers → 终端消费者

注意：公开资料没有证明这些 bazar 客户中有多少属于华人经营，也没有披露华人百货客户名单，因此不得把 M2TEC 直接归类为“华人批发商”或声称其客户主要为华人百货。

## 4. 自有品牌与供应结构

M2TEC 官网称其有两大自有品牌 M2TEC 与 Greenlyca，并在页脚写明其为 M2tec 与 Green Lyca 的“Distribuidor Oficial”。官网还称拥有直接供应商及制造协议、在西班牙有自有仓储和现货。

这支持以下公开事实：M2TEC不仅是多品牌批发商，也经营自有/自主管理品牌货盘。

## 6. 数据冲突 / 数据治理

M2TEC官网当前存在明显的SKU规模口径矛盾：
- 西语“Sobre nosotros”页面：10,000+ references
- 英语“About us”页面：50,000+ references

因此知识库不应把“50,000+ SKU”作为唯一当前事实。当前建议写法：
“官网不同语言/页面对目录规模存在10,000+与50,000+的冲突；10,000+在西语首页和西语公司页重复出现，50,000+仅见于英语公司页，需TO VERIFY。”
