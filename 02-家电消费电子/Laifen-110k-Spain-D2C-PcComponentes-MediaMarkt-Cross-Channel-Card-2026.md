## 4. 渠道路径（INFERENCE）

基于以上公开listing，可以建立以下研究模型，但不得升级为未经验证的采购事实：

### Path A — 品牌D2C

Laifen / 欧洲电商运营主体 → Laifen EU西语官网 → Spain消费者

### Path B — PcComponentes 1P

Laifen供应链 / 其经销体系 → PcComponentes 1P → Spain消费者

> **INFERENCE**：公开页面只能证明PcComponentes为终端Seller；上游究竟直接向Laifen采购还是通过分销商采购，当前没有公开证据。

### Path C — Marketplace

Laifen供应链 / 批发或跨境渠道 → Marketplace Seller（如MBOtechES / Cdiscount / Focus Electrofoto）→ PcComponentes或MediaMarkt Marketplace → Spain消费者

> **INFERENCE**：Seller存在不等于Seller是Laifen授权总代，也不等于平台中央采购该品牌。
